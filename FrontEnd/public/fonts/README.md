# Phông chữ PDF

Noto Sans Regular và Bold hỗ trợ dấu tiếng Việt trong PDF tải từ GOM.
Các file được phục vụ từ chính website, chỉ tải khi người dùng xuất PDF.

Nguồn: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Giấy phép: SIL Open Font License 1.1, xem `OFL.txt` kèm theo.
