The globe uses art textures generated locally from Natural Earth 1:110m land data.

- Data: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson
- License: public domain, https://www.naturalearthdata.com/about/terms-of-use/
- Retrieved: 2026-11-22
- Generator: `FrontEnd/scripts/generate-globe-textures.py` (Pillow).

`surface.webp` provides the project's green palette and fine grid; `relief.webp`
and `roughness.webp` give land and sea distinct lighting. These are decorative
land silhouettes, without political borders. All textures are bundled locally.
